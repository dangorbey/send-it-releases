# Send It

Installers for Send It, a Premiere Pro export panel. Get the newest from [Releases](https://github.com/dangorbey/send-it-releases/releases/latest):

- **Mac:** `send-it-<version>-mac.pkg`. Double-click it, then restart Premiere.
- **Windows:** `send-it-<version>-windows.zip`. Unzip it, double-click `Install Send It.cmd`, then restart Premiere.

Then open Window > Extensions > Send It. The "Source code" files GitHub adds to each release only contain this page.
